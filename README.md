# ClientVault AI — High-Converting B2B Lead Intelligence Platform

ClientVault AI is a curated B2B intelligence directory and digital product storefront designed to sell verified leads and outreach data to agencies, freelancers, and B2B service providers.

## Features
- **100% Free Hosting Ready:** Optimized for instant zero-config deployment on Vercel or GitHub Pages.
- **Conversion-Optimized UI:** Dark-mode institutional design, Tailwind CSS, Lucide icons.
- **Interactive Directory:** Instant client-side search across companies, tech stacks, and industries.
- **Direct Monetization:** Built-in modal wired to Gumroad or Stripe for instant checkout.
- **Zero Ongoing Server Costs:** Pure client-side data rendering with static JSON and CSV.

## Quick Start
1. Update `CHECKOUT_URL` in `app.js` with your Gumroad product checkout link.
2. Push to GitHub.
3. Import into Vercel for instant deployment.
